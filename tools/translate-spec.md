# 字幕翻译规范（供 AI 执行）

本文件是 `translations/pb-s2/eNN.json` 的唯一生产规范。执行者必须严格遵守。

## 0. 输入 / 输出

- 输入：`clean/pb/S02E<NN>.json`，格式为 `[{"en": "英文句子", "start": 秒, "end": 秒}, ...]`，已按句合并。
- 输出：`translations/pb-s2/e<NN>.json`，UTF-8 无 BOM，格式：

```json
{
  "ep": 11,
  "zh": ["第 1 句的中文", "第 2 句的中文"],
  "notes": { "12": "讲解文字", "40": "讲解文字" },
  "picks": [12, 40, 88],
  "w": { "12": { "line": "线（本句指台词）" } }
}
```

- **`zh` 数组长度必须严格等于输入句子数**，顺序一一对应，不许合并、不许拆分、不许跳过。
- `notes` 的 key 是句子下标（从 0 开始，字符串），value 是讲解。
- `picks` 是句子下标数组（数字）。
- `w`（可选）：`{句子下标: {单词: "本句译法"}}`。只在某个词在这一句里的意思
  和全局词库的通用义明显不同时才写，界面会标「本句译法」。不要滥用。

## 1. 逐句翻译规则

1. **口语化中文**，不是书面翻译腔。人物说话要像中国人真的会这么说。
2. **保留语气力度**：骂人要骂出来，威胁要有威胁感，玩笑要能笑。不许弱化成"他表达了不满"。
3. **人物语言区分**：
   - Michael 冷静、克制、用词精确，常带技术性比喻。
   - Lincoln 直、短、粗，句子常不完整。
   - T-Bag 油滑、爱押韵、爱用老派俚语和羞辱性称呼。
   - Sucre 热情、情绪化、常带西语词。
   - Mahone 冷、礼貌到发寒、爱用反问。
   - Bellick 粗鄙、自大、爱用体能威胁。
   - Abruzzi 阴沉、简短。
4. **不许编造剧情**。听不清或纯语气词（"Huh." "Mm."）就译成对应语气词（"嗯。""啊？"），不要脑补内容。
5. **专名统一**：Michael 迈克尔 / Lincoln 林肯 / L.J. L.J. / T-Bag T-Bag / Sucre 苏克雷 / Mahone 马洪 / Sara 萨拉 / Kellerman 凯勒曼 / Bellick 贝利克 / Abruzzi 阿布鲁齐 / C-Note C-Note / Fox River 狐狸河 / Company 公司 / Bolshoi Booze 博尔绍伊酒 / Panama 巴拿马。
6. 称呼语保留口语感："sir" → "长官/先生"（按语境），"boss" → "老大"，"man" → 常省略或"哥们"。
7. 省略号句（原句被切断）译成同样被切断的中文，不要补全。
8. 重复句照译重复，不要合并。

## 2. 讲解（notes）规则

- 每集 **30–45 条**，覆盖真正的难点，不是凑数。
- 每条 **15–60 字**，只讲一个点。
- 类型：习语 / 语法结构 / 双关 / 文化背景 / 语气微妙处。
- 禁止"这句话的意思是……"这种废话开头，直接讲点。
- 格式范例：
  - `"travel light = 轻装出行。"`
  - `"ain't 在此处等于 am not，黑人/南方口音常用。"`
  - `"双关：字面'捶肉'，俚语指自慰。"`
  - `"虚拟语气：If I were you, I would... 与现在事实相反。"`

## 3. 精选（picks）规则

- 每集 **20–35 条**（约全集的 4–6%）。
- 选择标准（满足其一即可）：
  1. 语法价值高（虚拟语气、倒装、完成时、被动、从句嵌套）
  2. 习语/俚语密度高
  3. 剧情关键句（转折、揭示、威胁、告别）
  4. 字面易误读的句子
- `picks` 必须是升序、无重复、且在 `[0, 句子数)` 范围内。
- 尽量让 `picks` 与 `notes` 的 key 有重叠，但不必完全一致。

## 4. 自检（必须执行）

写完 JSON 后运行：

```
python tools/_diff.py e<NN>
```

必须输出 `en <N> zh <N>` 且两个数字相同。若不同，补齐或删掉多余条目后重跑。

然后（可选但推荐）运行：

```
python tools/apply-translations.py --show pb --season 2
```

确认该集显示 `100.0%`。

## 5. 严禁事项

- 不许只翻译一部分句子然后留空。
- 不许用"（此处省略）""……"占位代替译文。
- 不许把 `zh` 写成字符串而不是数组。
- 不许改动 `clean/pb/*.json`。
- 不许改动 `assets/js/data/pb-s2/*.js`（由脚本生成）。
